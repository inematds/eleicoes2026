Durante a apuração, arquivos de horários diferentes não batem, e isso é normal. Um número fora do padrão não é prova de nada; só indica onde olhar com mais cuidado.

1. As somas fecham?

Brasil = 27 estados + exterior, e cada estado = soma das suas cidades, campo a campo

Brasil = 27 UFs + exterior

Cada estado = soma das cidades (2º turno)

A soma das cidades só é comparada quando todas as cidades do estado têm resultado final e o arquivo do estado também está com 100% das seções. Antes disso o status é “pendente”, com quantas cidades faltam.

2. Os arquivos guardados são os originais?

Cada arquivo baixado do TSE fica guardado sem alteração, com a “impressão digital” (sha256) no nome

Bloqueios automáticos do INEMA

O bloqueio é a trava de segurança do próprio INEMA: antes de publicar, o coletor confere cada arquivo do TSE. Se os números andarem para trás, se a hora voltar no tempo ou se a soma não fechar, o arquivo fica guardado mas não vai para o painel. Isso costuma acontecer quando a rede de distribuição do TSE entrega por alguns segundos uma cópia mais antiga.

3. Exterior: boletins de urna x total oficial

—

O boletim de urna é o papel (e o arquivo) que cada urna imprime ao fim da votação, com os votos daquela seção. O INEMA baixa o boletim de cada seção do exterior e soma por conta própria. A conta só fecha quando 100% das seções tiverem o boletim lido; até lá, nenhuma soma parcial pode passar do total oficial.

Como esta conferência é feita

Fonte, critérios e limites

Fonte

  • Só arquivos oficiais do TSE já baixados pelo INEMA: resultado do Brasil, de cada estado e do exterior, resultado de cada cidade e boletins de urna do exterior.
  • Cada arquivo original fica guardado com data, hora e sha256. Nada é reescrito.
  • A página busca a conferência mais recente de 2 em 2 minutos; a hora em que as contas foram refeitas aparece no resumo.

Critérios

  • Conferido: todos os campos comparados são iguais.
  • Pendente: falta arquivo, a apuração não fechou ou os arquivos são de horários diferentes.
  • Divergência reproduzida: diferença que continua com arquivos da mesma atualização. Pede explicação, não é conclusão.
  • Todo indicador mostra quantos conferiram, de quantos, quando e por qual regra.

Limites desta fase

  • Ainda não confere boletins de urna no Brasil, assinaturas digitais nem registros das urnas.
  • O resultado só é final quando o TSE fecha a totalização; até lá os números podem mudar algumas décimas.
  • Um padrão fora do comum não diz a causa. Diferenças podem vir de versões, retificações ou da própria coleta.
